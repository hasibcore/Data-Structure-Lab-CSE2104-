# Offline Assignment 4 - Singly Linked List

This repository contains the implementation for **Data Structure Lab (CSE2104) - Offline Assignment 4**.

## Features Implemented
The C++ file (`00724205101098_Offline4.cpp`) implements a fully functional singly linked list using `malloc()` and `free()` for memory management. The following operations are supported:

1. **insertFirst(value):** Inserts a new node at the beginning.
2. **lastInsert(value):** Inserts a new node at the end.
3. **insertAtPosition(position, value):** Inserts a new node at a specific position.
4. **insertAfterValue(search_value, new_value):** Inserts a new node after a specific value.
5. **deleteFirst():** Deletes the first node.
6. **deleteLast():** Deletes the last node.
7. **deleteAtPosition(position):** Deletes a node at a specific position.
8. **deleteByValue(value):** Deletes a node containing a specific value.
9. **display():** Prints the linked list.
10. **search(value):** Searches for a value in the list.
11. **last_node():** Prints the value of the last node.
12. **previous_of_last_node():** Prints the value of the node just before the last node.
13. **list_size():** Prints the total size of the linked list.
14. **reversePrint():** Prints the linked list in reverse order.
